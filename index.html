03 Pre-flight

  1. Galaxy on One UI 8+ (Android 16). Older firmware can't run DeX on a virtual display.
  2. USB debugging on: Settings → About phone → Software info → tap Build number 7×, then Developer options → USB debugging.
  3. Phone → tablet/phone? The display device must be the USB host. If nothing shows up, pull down notifications on the display device → USB → “USB controlled by: this device”.
  4. Accept the RSA prompt on the phone the first time (tick “Always allow”).
